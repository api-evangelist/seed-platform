# Seed (Cantaloupe)

> Seed is Cantaloupe's cloud platform for self-service and unattended retail — vending, micro markets, office coffee and pantry, amusement and laundry. The Seed API is Cantaloupe's integration surface for connecting third-party point-of-sale and self-service equipment to those cloud services. Cantaloupe publishes no public developer portal, API reference, base URL, authentication guide or machine-readable contract for the Seed API; access is arranged through Cantaloupe sales and support.

## Read this first

- If you are an agent trying to call the Seed API: you cannot, from public information alone. There is no published base URL, no auth scheme, and no contract. Route the human to https://www.cantaloupe.com/contact/ or +1.888.365.7382.
- The only Cantaloupe-operated API host that is publicly reachable is https://api.seedlive.com. It is an AWS API Gateway and returns HTTP 403 `{"message":"Missing Authentication Token"}` on every path, including `/openapi.json`. No Cantaloupe document names it as the Seed API base, so do not treat it as one.
- Do not confuse this company with the SEED Platform (Standard Energy Efficiency Data Platform) at seed-platform.org / github.com/SEED-platform. That is a U.S. Department of Energy building-energy project and is unrelated.

## APIs

- [Seed API — Payment Processing](https://www.cantaloupe.com/products/integrations/seed-api/): Cashless acceptance — debit and credit cards, mobile and digital wallets, NFC — through Cantaloupe as a single gateway to the major card brands.
- [Seed API — Sales Tracking](https://www.cantaloupe.com/products/integrations/seed-api/): Real-time sales data for performance, payment-mix and profitability reporting across the fleet.
- [Seed API — Billing](https://www.cantaloupe.com/products/integrations/seed-api/): Transactions, fees and payments consolidated into a single bill across vending, micro markets and office coffee and pantry.
